# Herkunft des Verkaufstons

`sale-cash-register.wav` ist ein kurzer Ka-ching-Effekt aus aufgenommenen
mechanischen Geräuschen und einer Glocke. Er ersetzt die bisherige synthetische
Tonfolge für Verkäufe.

## Quelle und Lizenz

- Original: [Cash Register Fake.wav von CapsLok](https://freesound.org/people/CapsLok/sounds/184438/).
- Lizenz: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/),
  auf der Originalseite ausdrücklich angegeben.
- Verwendete Kurzfassung: [Cha-ching von Slap Alert](https://slapalert.com/sounds),
  dort ebenfalls als CC0 ausgewiesen.
- [Direkter WAV-Download](https://slapalert.com/assets/sounds/cha-ching.ad14525b.wav),
  abgerufen am 9. November 2026. Die heruntergeladenen Bytes sind unverändert.

Der Originalautor beschreibt einen aus Druckerklappen, einer geschüttelten
Kiste, einer Ratsche und einer kleinen Glocke zusammengesetzten Effekt.
Die Datei ist keine Originalaufnahme von Shopify oder eBay.
