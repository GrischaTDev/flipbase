# Vorlage für Discord-Beta-Updates

Juna verwendet diese Vorlage nur, wenn der Nutzer im Chat eine neue
Discord-Update-Nachricht anfordert. Die Nachricht wird zuerst als Entwurf im
Chat gezeigt. Version und Punkte stammen aus den seit dem letzten bestätigten
Update tatsächlich ausgelieferten Nutzeränderungen.

```text
**Flipbase Beta-Update · v<VERSION>**

• **Hinzugefügt:** Auf <SEITE> kannst Du jetzt <NEUE MÖGLICHKEIT>. Dadurch <NUTZEN>.
• **Geändert:** Auf <SEITE> funktioniert <AKTION> jetzt <NEUER ABLAUF>. So <AUSWIRKUNG>.
• **Entfernt:** <BISHERIGE FUNKTION> entfällt. Nutze stattdessen <ERSATZWEG>.
• **Behoben:** <PROBLEM> tritt bei <AKTION> nicht mehr auf. Du kannst <ERGEBNIS>.
```

Nur passende Kategorien übernehmen und Platzhalter vollständig ersetzen.
Ein bis fünf kurze Punkte reichen. Keine technischen oder vertraulichen Details
einfügen. Ein Link gehört nur hinein, wenn sein Ziel öffentlich und freigegeben
ist.
